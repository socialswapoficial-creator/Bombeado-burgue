# Boi Bread Burguer

Site estático completo: HTML, CSS, JavaScript, imagens e vídeos. Não precisa instalar dependências nem executar build.

## Enviar ao GitHub

1. Extraia este ZIP.
2. Abra o repositório Bombeado-burgue no GitHub.
3. Selecione **Add file → Upload files**.
4. Envie o conteúdo desta pasta, incluindo a pasta assets. O arquivo index.html deve ficar na raiz do repositório.
5. Confirme em **Commit changes**.

## Publicar no GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main** e pasta **/(root)**. Salve e aguarde a publicação.

## Abrir no computador

Na pasta do projeto, execute `python3 -m http.server 8000` e abra http://localhost:8000.

## Arquivos

- index.html: página principal.
- historia.html: página de história.
- style.css, dark.css e motion.css: aparência e animações.
- Arquivos .js: cardápio, sacola, favoritos, opções, vídeos e animações.
- assets/: imagens, texturas e vídeos locais.

## Estado das funcionalidades

O cardápio, as opções dos produtos, os favoritos e a sacola funcionam no navegador. Pedidos, envio para WhatsApp e pagamentos ainda não estão integrados. Os horários de sexta e sábado precisam ser confirmados com a loja.
